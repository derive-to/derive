# Roadmap

The canonical roadmap is a living Derive artifact — maintained by an agent through
review rounds, versioned on every revision, embedded at
**[derive.to/roadmap](https://derive.to/roadmap)**. This file is a snapshot of its
themes; the page is always current.

## Now

- **Ship the shelf** — faster agent reads, origin isolation, organize, the activity
  feed, deploy on merge.
- **The golden path** — your first session ends with the publish → review → revise
  loop closed once.

## Next

- **Public launch** — fair source, one container, hosted at derive.to.
- **Adoption, instrumented** — sign up, connect an agent, publish, close the loop.
  Measured.
- **Living artifacts, v1** — a maintainer, a cadence, a freshness promise. The
  roadmap page is the prototype.

## Later

- Standing documents that keep themselves current through review safety.
- Self-improving contexts: agent memory as reviewed, versioned files.
- The one-turn primitive: your turn, the agent's turn, or settled.
- Review from your pocket.
- The agent trust surface: scoped tokens, per-agent audit.
- Search at true scale.

## The long pole

**Real origins for artifacts.** Every artifact gets a real, unguessable origin of its
own — storage, routing, app-class behavior. The last dependency is the Public Suffix
List, reviewed in months, not weeks; it files first, and app-class artifacts land
when propagation completes.

## Influencing it

Open an issue for anything you want moved, added, or argued with. The roadmap page
takes comments directly — the maintainer picks them up in review.
