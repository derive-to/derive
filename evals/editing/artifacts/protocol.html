self-improving test system · operating contract

Luna explores. Deterministic tests decide.

The loop separates generative adversarial discovery from reproducible judgment. Luna agents search for counterexamples; only minimized, deterministic failures can change code or enter the permanent corpus.

Goal

Make every source-backed edit preserve user intent, authored structure, identity, unrelated bytes, and version history across Markdown, HTML, decks, videos, and browser persistence.

Evaluate

Run the risk-weighted corpus through core, API, and browser lanes; compare exact source/state or require explicit safe refusal; then run pnpm verify.

Stop

One complete Markdown + HTML + deck/video Luna exploration round produces no new reproducible P0–P2 defect, all three lanes stay green, and the exact repository verification gate passes.

One improvement cycle

01Generate attacksThree surface-specialist Luna agents mutate context, syntax, identity, order, and timing.
02ReproduceTranslate the candidate into a runnable operation against current code.
03MinimizeShrink source and operation sequence while retaining the failure.
04Classify oracleChoose exact source, identity, version, sanitization, bounded runtime, or safe refusal.
05Patch narrowlyRepair the responsible mapper/operation; preserve adjacent authored behavior.
06PromoteAdd a stable ID and literal test declaration to the permanent corpus.
07Evaluate gatesCore → API → real browser → exact repository verification.
↺ New regressions and uncovered seams feed the next Luna exploration round

An agent may propose anything; the loop accepts only evidence with an explicit oracle and reproducible operation sequence.

Promotion rules

  1. The bug reproduces on the current branch.
  2. The test fails for the intended reason before the patch.
  3. The smallest meaningful source still fails.
  4. The oracle observes persisted truth—not just a toast or screenshot.
  5. The stable scenario ID is declared literally and registered in the manifest.
  6. Unrelated authored source/state is asserted when preservation is the risk.

Guardrails against false confidence

  • Do not let source-shaped DOM stand in for rendered Markdown.
  • Place preservation assertions in the same authored block.
  • Exercise real REST routes, not only core helpers.
  • Validate malformed, unknown, and no-op operations explicitly.
  • Control race ordering; never depend on scheduler luck.
  • Use wall-clock bounds only as a smoke oracle, not a performance contract.
Execution boundary: Derive holds the reviewable policy, evidence, and corpus map. The CLI/harness and agents execute the loop; the artifact itself does not autonomously run code.
