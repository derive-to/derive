# Living status example

This example is meant to be revised repeatedly at the same URL. It favors decisions,
owners, evidence, and changed assumptions over a chronological wall of activity.

[Open the official live example](https://derive.to/artifacts/example-living-status-f49k4yvg).

```bash
derive publish --name "Baseline"
# Update status.md after feedback or new evidence, then:
derive publish --name "Decision update"
```

Suggested recurring review request:

> Verify changed metrics, challenge blocked items without evidence, and resolve decisions
> that now have an owner and next action. Request changes if any number lacks a source or
> any risk lacks a trigger.
