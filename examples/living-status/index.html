Since the last update

This section is the difference between the version read last week and this one. It is allowed to move backwards.

Reversed
The recovery test went from done back to open. The earlier run used a file with no failures in it, so it never exercised the restart path it was meant to prove.
Decided
Malformed rows are rejected rather than imported blank. A silent empty date surfaced weeks later in reporting. A loud failure at import is cheaper than a quiet one in a report.
Added
Encoding variance is now a tracked risk. A pilot file arrived in an older encoding. Not investigated yet, and named here so it is not discovered at open.

Not true yet

Listed so nothing above is read as covering it.

  • Concurrent imports into one workspace. Single-user testing only.
  • Files above 10 MB. The largest tested was 2.1 MB.
  • Automatic retry. A failed import waits for a person.
