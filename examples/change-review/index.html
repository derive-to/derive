What was actually run

Malformed rows now stop the row instead of importing a blank.

The importer used to accept a row whose date could not be parsed, store an empty value, and report success. That turned a visible failure into a silent one, which surfaced weeks later in reporting.

What broke while checking

Kept in the record rather than quietly fixed, because the cause explains why the partial-failure case is now a regression test.

Found and fixed

The mixed file returned a 500 on the first attempt.

The error collector held a reference to the open file handle, so serialising the response after the stream closed threw. It only appeared with a partial failure: a file that was entirely valid or entirely broken never hit it.
