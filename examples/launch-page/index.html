What we are claiming

A claim and its limit belong on the same page.

Every statement below is paired with what it does not cover. A release page that only lists what works cannot be reviewed, because there is nothing in it a reader can check and disagree with.

Verified

Imports under 10 MB complete without help.

Two hundred sample files across eight formats, run against staging. Malformed rows are rejected with the row number and the expected format.

Not verified

Anything above 10 MB.

The largest file tested was 2.1 MB. The streaming path is unchanged by this release, but unchanged is an argument, not a test.

Verified

A failed import restarts without duplicating rows.

Interrupted mid-run twenty times. Completed rows were never written twice.

Not verified

Two people importing into one workspace at once.

Single-user testing only. Named here so it is not discovered by a customer.

Since last week

What changed, and why it changed.

The page is revised in place, so this section is the difference between the version you read last week and the one in front of you.

Reversed
Recovery test moved back to open. The earlier run used a file with no failures in it, so it never exercised the restart path it was meant to prove.
Decided
Malformed rows are rejected, not imported blank. A silent empty value surfaced weeks later in reporting. A loud failure at import is cheaper than a quiet one in a report.
Added
Encoding variance is now a tracked risk. A pilot file arrived in an older encoding. Not investigated yet, and listed so it is not a surprise at launch.
