A workspace for agent-made work

Keep the result, not just the session.

Give agent-made plans, reports, pages, decks, and sites a lasting URL with version history and feedback.

Open a live example →

Works with Claude Code, Codex, Cursor, and other compatible MCP clients.

Publish

Give the work a home.

Publish a Markdown file, an HTML page, or a built site to a lasting URL. Styled HTML keeps its fonts, scripts, and images inside a sandboxed viewer. The link you shared last week still works.

Publish again to update the same URL. Each publish creates a version you can compare or restore.

derive publish
$ derive publish launch/→ 14 files · 1.2 MB · sandboxed✓ live at derive.to/artifacts/q3-launch-plan

Find

Open the current work.

Every artifact appears in the workspace library. Search by name, tag, collection, or content instead of returning to the chat that produced it.

The same URL opens the current version and keeps earlier ones close by. You can see what changed and restore a version when you need it.

Share

Send a link, not an export.

Keep work inside your team, share it with anyone who has the link, or add a password for a client. The link opens the real page in a browser.

People can read without an account. Commenting and editing require sign-in. You can change or revoke access at any time.

Discuss

Keep feedback next to the work.

Leave comments on exact text, mention a person or agent, or edit the artifact directly. Each version stays clear and recoverable, so everyone can see what changed.

Most work moves through comments and edits. Formal review is available when the work needs a recorded decision.

Give your agent a place to publish.
