Use one

Publish with the workspace default.

The example configurations intentionally omit access fields so cloning one never widens visibility without your decision.

git clone https://github.com/derive-to/derive.git
cd derive/examples/launch-page
derive login
derive publish
Then keep going only if useful. Open or share the artifact, comment on the exact output, let a compatible agent publish a focused revision, or request formal approval when the work truly needs a named decision.
Proof standard

What we will and will not call evidence.

Official samples stay labeledIllustrative metrics, companies, and scenarios are never presented as customer results.
Customer stories require consentA real case names the use, starting point, changes, outcome, and the limits its participant allowed us to publish.
Different uses stay differentA private library, a shared page, an ongoing discussion, and formal approval are distinct valid uses—not one funnel.
