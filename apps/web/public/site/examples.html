FIG. 02 · Clone and publish

Start from one.

Each example ships its source and a small config. Access is deliberately left out, so a copy you publish takes your workspace default instead of inheriting ours.

git clone https://github.com/derive-to/derive.git
cd derive/examples/technical-plan
derive login
derive publish
Then change it. Edit the file, publish again, and the link you already shared does not move. What changed lives in the version history instead of a follow-up message.
