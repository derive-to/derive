Security and abuse

Report a problem

Derive hosts pages and documents published by its users, including pages on derive.page. Tell us if you find phishing, malware, impersonation, another form of abuse, or a vulnerability in Derive itself.

Abusive content

abuse@derive.to

Send the full URL and a short description of the problem. A person reads every report. We remove confirmed phishing and malware as quickly as possible.

Security vulnerabilities

security@derive.to

Use this address for vulnerabilities in the Derive app, API, or user-content hosting. Include enough detail for us to reproduce the problem, and give us a reasonable window to fix it before public disclosure. The server is source available, so code issues are also welcome on GitHub.
