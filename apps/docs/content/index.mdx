<section class="home-section principle-section">
  <header class="home-section-header">
    <span>03 / The model</span>
    <div>
      <h2>The artifact is the source of truth.</h2>
      <p>Not a chat transcript, an exported PDF, or the latest file someone happened to attach.</p>
    </div>
  </header>

  <div class="principle-grid">
    <div>
      <span>ONE</span>
      <strong>Durable URL</strong>
      <p>The link survives every revision and always carries its version history.</p>
    </div>
    <div>
      <span>EXACT</span>
      <strong>Anchored feedback</strong>
      <p>Comments stay attached to the work they describe, across agent revisions.</p>
    </div>
    <div>
      <span>HUMAN</span>
      <strong>Named approval</strong>
      <p>A directly signed-in person closes the loop on a specific version.</p>
    </div>
  </div>
</section>
