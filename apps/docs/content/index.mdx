## The shortest useful explanation

1. Publish HTML, Markdown, or a complete static site.
2. Share the artifact's durable URL with the people who should review it.
3. Reviewers comment on exact text and approve a named version or request changes.
4. Your agent reads open feedback, revises the same artifact, and asks for review again.

The content, every version, each thread, and the final decision stay together. The source
of truth is the artifact—not one model's chat history.

## Hosted and self-hosted are the same product

The hosted service at [derive.to](https://derive.to/) is the fastest way
to start. The self-hosted image exposes the same web application, API, MCP server, and
review model on your infrastructure. Derive is Fair Source today; see
[Licensing](/reference/licensing/) for the exact terms and conversion schedule.
