# Artifact runtime

Derive uses `@aniraga/open-artifact-runtime/shared` for collection state.
The shared client owns optimistic values, reconciliation, subscriptions, and rollback.
It uses the same collection rules as the server.

The kit and Derive use `@aniraga/open-artifact-server/collections` for saved mutations.
The module reads, applies the mutation, and retries a lost compare-and-swap.
Derive adapts its existing metadata store. It keeps access checks, rate limits,
actor attribution, live broadcasts, and the activity ledger.
The module reports whether a result is saved. A changed result identifies its item.
The host sends side effects only after the write succeeds.

The kit and Derive use `prependArtifactHead` for runtime insertion.
The shared scanner skips comments, raw text, templates, and quoted attributes.
It preserves a leading charset declaration and inserts before authored CSP.

`shared-collection-client.ts` adapts Derive's existing messages to `StateBackend`.
It preserves `derive.shared`, `derive.increment`, the handle's return values,
caller slots, and the existing activity fields. It uses Derive's ownership fields.
Authored fields named `__actor` or `__slot` remain ordinary data.

The host keeps authentication and artifact access. It also checks browser activation
before each mutation. The opaque iframe receives no host cookies.

The adapter accepts responses only from its parent window. It validates snapshots
before it changes state. Older responses cannot replace a newer saved snapshot.
A failed mutation restores the last saved value before the caller receives the error.
A resync runs in the background.

`shared-state-client.ts` keeps Derive's content readiness and error reporting.
It uses the collection transport's host handshake. One message listener handles
the handshake, collection responses, and resync messages.

Run `pnpm build:shared-client` after changing the adapter or its runtime dependency.
The build creates `shared-collection-client.gen.ts`. Do not edit this file directly.
The existing client guard checks the generated bundle before delivery.

The collection client is one completed runtime seam. The full artifact kit,
anchor client, frame bridge, React reader, and format controls still need adoption.
