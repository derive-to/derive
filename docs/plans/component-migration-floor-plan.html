Code hygiene · enforced, not hoped for

  • tokensColor only via token utilities. No #hex, no var(--x) inside .tsx — text-foreground / bg-card / border-border follow the active theme. This is what makes dark mode correct by construction.
  • typeOne type scale. Only text-2xs … text-3xl (10 → 28px). Ban arbitrary text-[13px] and every inline fontSize.
  • sortAuto-sorted classes via Biome useSortedClasses — deterministic order, no bikeshedding.
  • size~400 LOC soft cap per file. Forces the splits to stick; a file growing past it is a smell to extract.
  • cleanupLegacy styles.css shrinks to zero. Only the [data-theme] token blocks survive (folded into globals.css); dead classes deleted as each surface lands.
