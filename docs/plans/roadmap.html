01 Performance & best practices

Make navigation feel instant and the app stay fast as the library grows, using the TanStack data + prefetch model the ecosystem has converged on (Tanner Linsley), plus the modern measurement + render-hygiene tooling (Aiden Bai's react-scan / million, the React Compiler, web-vitals).

The headroom: defaultPreload: "intent" is already on, so hovering a Link prefetches the route's code — but there are no route loaders, so it never prefetches data. Today 11 files fetch in useEffect after mount: waterfalls, refetch-on-every-mount, no dedup, no cache. Close that gap and everything else compounds on it.

Tier 1

Finish prefetch + fix the data layer

now · biggest win

Adopt TanStack Query + route loaders so the already-on intent preload warms data + code on hover. Highest leverage; the rest builds on it.

  • Route loaders → queryClient.ensureQueryDataTanner artifact route warms getArtifact + listComments; library warms listArtifacts; shell summary/collections/workspaces become queries (dedup + cache, no refetch-on-mount, kills the 4-request load waterfall).
  • defaultPreloadStaleTime: 0 so the loader defers to Query's cache (per the Router docs).
  • Prefetch the artifact's raw HTML (the iframe src) on card / ⌘K / rail hover via <link rel="prefetch"> — the iframe paints instantly on open.
  • Net: hover a card / palette row / rail item → route + data + iframe bytes all warm → navigation feels instant.
Tier 2

Perceived-perf polish

next

Make every transition feel intentional, never blank.

  • pendingComponent + defaultPendingMs skeletons on a slow nav instead of a blank flash.
  • View Transitions (defaultViewTransition: true) smooth cross-fade on route change; the rail is persistent so only the content morphs. The visible "wow".
  • Tune defaultPreloadDelay ~50–80ms so brief hovers don't over-fetch (intent is the mobile-safe mode).
Tier 3

Lists + bundle

next

Stay 60fps as libraries grow; ship lean JS on the first route.

  • @tanstack/react-virtualTanner for the library grid + flip "Load more" → infinite scroll (useInfiniteQuery); render only visible cards.
  • Lazy-load the heavy bits ReviewOverlay, the cmdk palette, Dialog/Sheet, the comment machinery — leaner library-route bundle.
  • rollup-plugin-visualizer + a CI bundle budget so phosphor / radix / cmdk weight can't silently regress.
Tier 4

Measure + render hygiene

next

See the real numbers; kill wasted renders.

  • react-scanAiden Bai in dev to surface needless re-renders. Prime suspect: the AppShell context value is a fresh object each render → every useShell consumer re-renders on any shell change. Fix: useMemo the value + split stable vs volatile context.
  • web-vitals beacon real LCP / INP / CLS from prod.
  • React Compiler (stable in React 19) auto-memoization; also retires the manual useMemo/useCallback + exhaustive-deps papercuts.
  • million.jsAiden Bai only if the grid is still the bottleneck after virtual + the compiler.
Tier 5

Network + caching

later

Load bytes once.

  • Cache-Control: public, max-age=31536000, immutable on /raw/<id>/v/<n>/* (versioned + immutable) and Vite's hashed assets → thumbnails + iframes cache hard.
  • Brotli/gzip on the Hono responses; Fly already gives HTTP/2.

Sequencing: ship Tier 1 on a branch, wire react-scan + web-vitals first so we have honest before/after numbers (Lighthouse + INP), then Tiers 2–5 in order. Each tier is independently shippable.

02 Agents & MCP

Derive as a first-class surface for AI agents: publish, version, review, and read artifacts programmatically. Builds on the existing Settings → Agents (API-token agents) and the packages/mcp server.

Draft — needs shaping with you. Direction: make an agent a real workspace actor (it already acts in its own workspace) with scoped, auditable access, and make the MCP surface the primary way agents drive Derive. Sections below are a starting cut, not committed scope.
A1

Scoped, expiring agent tokens

draft

Tokens that grant least privilege, not a blanket key.

  • Per-token role + scope (read / publish / review) and optional collection scoping; expiry + rotation.
  • Reuses the existing agent role model + hashed-token storage; adds scope columns.
A2

Agent activity + audit

draft

See what every agent did, in Settings.

  • Per-agent timeline publishes / proposals / reads, with the artifact + version; last-used + revoke.
A3

MCP as the agent surface

draft

Harden packages/mcp into the canonical agent integration.

  • Tools publish / propose / read / list — mapped to the scoped token; agents propose, humans approve (ties into the review flow).
  • Per-agent rate limits reuse the per-actor write limits (quotas already exist).
